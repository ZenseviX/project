# หน้าเว็บ Thai Chart Patterns

คู่มือหน้าเว็บ (Dashboard) ของโปรเจกต์ **การวิเคราะห์และจัดกลุ่มรูปแบบความนิยมของเพลงบนชาร์ต Spotify ประเทศไทยด้วย Machine Learning**
อธิบายว่าแต่ละหน้าทำอะไรได้ ใช้งานอย่างไร ข้อมูลมาจากไหน และแก้ไขหน้าเว็บอย่างไร

> หน้าเว็บนี้แสดงผลที่ Python คำนวณไว้แล้ว (`dashboard.json`) จึงไม่ต้องใช้อินเทอร์เน็ต, Spotify API หรือ GPU
> ส่วนที่คำนวณในเบราว์เซอร์มีเพียง Cosine Similarity, การไต่อันดับ และการสลับโมเดล ซึ่งใช้ข้อมูลในไฟล์เดียวกัน

## 1. เปิดหน้าเว็บ

รันในโฟลเดอร์โปรเจกต์ (ไม่ต้องติดตั้ง Node.js เพราะมีไฟล์ที่ build แล้วใน `frontend\dist`):

```powershell
python -m thai_chart_ml run      # คำนวณผล (ครั้งแรก หรือเมื่อข้อมูลเปลี่ยน)
```

## 2. ส่วนประกอบหลักของหน้าจอ

```
┌────┬──────────────────────────────────────────┬──────────────┐
│ 📊 │ ชื่อหน้า                   [โมเดล ▾]      │ โมเดลที่ใช้อยู่ │
│ 📈 │──────────────────────────────────────────│ ไต่แรงสุด 7 วัน │
│ ◈  │                                          │              │
│ ♫  │              เนื้อหาของหน้า                │ เพลงตั้งต้น    │
│ 🗄 │                                          │ (ปก + กราฟ)   │
│ ☀  │                                          │              │
└────┴──────────────────────────────────────────┴──────────────┘
 เมนู                  เนื้อหาหลัก                    แถบขวา
```

- **เมนูซ้าย** — 5 หน้า และปุ่มสลับธีมมืด/สว่างด้านล่าง (บนมือถือเมนูย้ายไปเป็นแถบล่างจอ)
- **ตัวเลือกโมเดล** มุมขวาบน — เปลี่ยนวิธีจัดกลุ่มของทุกหน้า ([ข้อ 8](#8-ตัวเลือกโมเดล))
- **แถบขวา** (แสดงทุกหน้า)
  - *โมเดลที่ใช้อยู่* — ชื่อโมเดล, k, Silhouette, Hard/Soft · ปุ่ม "เปรียบเทียบ" ไปหน้าโมเดล
  - *ไต่แรงสุด 7 วัน* — 5 เพลงที่อันดับขึ้นมากที่สุดในสัปดาห์ล่าสุด คลิกเพื่อตั้งเป็นเพลงตั้งต้น · "ทั้งหมด" ไปหน้าไต่อันดับ
  - *เพลงตั้งต้น* — ปกเคลื่อนไหว ชื่อเพลง เส้นประวัติอันดับ กลุ่มของเพลง และปุ่มไปดูเพลงที่คล้ายกัน

**เพลงตั้งต้น (seed)** คือเพลงที่ใช้เป็นจุดเริ่มในการหาเพลงคล้าย เลือกได้จากหลายที่: คลิกจุดบนแผนที่ PCA,
คลิกเพลงในรายการไต่อันดับ, ค้นหาในหน้าเพลงคล้าย หรือคลิกชื่อเพลงในการ์ดเพลง ทุกหน้าใช้เพลงตั้งต้นเดียวกัน

## 3. หน้า ภาพรวม (Overview)

| ส่วน | ทำอะไรได้ |
|---|---|
| **KPI 4 ช่อง** | จำนวนเพลง, ช่วงวันที่มีข้อมูล, % เพลงที่จับคู่ข้อมูลเสียงได้, จำนวนกลุ่ม k และ Silhouette ของโมเดลที่เลือก |
| **Silhouette ต่อ k** | กราฟแท่งคะแนน Silhouette ของ k = 2–8 แท่งสีเขียวมะนาว = k ที่ถูกเลือก · ชี้เมาส์ดูค่าและขนาดกลุ่ม |
| **การ์ดมาแรง 7 วัน** | เครื่องเล่นจำลอง วน 5 เพลงที่ไต่แรงสุดทุก 6 วินาที ปกเป็นภาพ generative เคลื่อนไหว (สีคงที่ต่อเพลง) · ⏮ ⏯ ⏭ ควบคุม · คลิกชื่อเพลงเพื่อตั้งเป็นเพลงตั้งต้น |
| **แผนที่กลุ่มเพลง (PCA)** | ทุกเพลงเป็นจุดบนระนาบ 2 มิติ สี + รูปทรงบอกกลุ่ม · ชี้เมาส์ดูรายละเอียด · **คลิกจุด** เพื่อเลือกเพลงตั้งต้น · วงแหวน = เพลงตั้งต้น, จุดใหญ่ = 5 เพลงที่แนะนำ · คลิกชิปกลุ่มด้านบนเพื่อซ่อน/แสดงกลุ่ม |
| **การ์ดอันดับล่าสุด** | การ์ดเพลงสไตล์ Spotify ใต้แผนที่ PCA วนแสดงอันดับ #1–#5 ของวันล่าสุด พร้อมการเปลี่ยนอันดับ 7 วัน · ปกซูมช้าๆ แผ่นเสียงหมุน EQ เต้น แถบเวลาเลื่อน 7 วินาทีแล้วเปลี่ยนเพลง · ชี้เมาส์ค้าง = หยุดชั่วคราว · คลิกจุดด้านล่างเพื่อข้ามไปเพลงนั้น |
| **โปรไฟล์กลุ่ม** | การ์ดหนึ่งใบต่อกลุ่ม: จำนวนเพลงและสัดส่วน, ป้ายลักษณะกลุ่ม (เช่น *ขึ้นอันดับสูง · ติดชาร์ตช่วงสั้น · ถึงจุดสูงสุดเร็ว*), ค่ามัธยฐาน 4 ค่า (อันดับดีสุด, อันดับกลาง, วันบนชาร์ต, วันถึงพีค) พร้อมแถบเทียบกับกลุ่มอื่น และค่าเฉลี่ยเสียง dance / energy / valence ของเพลงที่จับคู่ได้ |

> ชื่อกลุ่มตั้งด้วยกฎจากค่ามัธยฐานเพื่อช่วยอ่าน ไม่ใช่ป้ายที่โมเดลเรียนรู้

## 4. หน้า ไต่อันดับ (Climbers)

ดูว่าเพลงไหน **กำลังไต่ขึ้น** เข้าใหม่ หรือร่วงลง โดยเทียบอันดับสองวัน

**ตัวควบคุม**
- **ช่วงเวลา** — เทียบเมื่อวาน / 7 วันล่าสุด / 30 วันล่าสุด
- **ณ วันที่** — แถบเลื่อนเลือกวันใดก็ได้ในช่วงข้อมูล (ปุ่ม "ล่าสุด" กลับไปวันสุดท้าย)
- **ไต่ขึ้น / เข้าใหม่ / ร่วงลง** — เลือกประเภทรายการ

**สิ่งที่แสดง**
- **KPI** — จำนวนเพลงที่ติดชาร์ตวันนั้น, จำนวนที่ไต่ขึ้น/ร่วงลง, เพลงที่ไต่สูงสุด, จำนวนเพลงเข้าใหม่
- **เส้นอันดับ Top 5** — อันดับรายวันของ 5 เพลงแรกในรายการ (แกนตั้งกลับด้าน: บน = อันดับดีกว่า) แถบไฮไลต์ = ช่วงที่เทียบ · ชี้เมาส์ดูอันดับรายวัน
- **เฉลี่ยตามกลุ่ม** — การเปลี่ยนอันดับเฉลี่ยของแต่ละกลุ่ม (แท่งขวา = ไต่ขึ้น, ซ้าย = ร่วงลง) เปลี่ยนตามโมเดลที่เลือก
- **Top Chart Climbers** — รายการ 10 อันดับ (สองคอลัมน์): อันดับปัจจุบัน, ป้าย ▲/▼ จำนวนอันดับ, กลุ่ม · คลิกเพื่อตั้งเป็นเพลงตั้งต้น

**นิยาม**

| ป้าย | ความหมาย |
|---|---|
| ▲ n | อันดับดีขึ้น n อันดับเทียบกับวันที่เปรียบเทียบ (ตัวเลขอันดับลดลง) |
| ▼ n | อันดับแย่ลง n อันดับ |
| ใหม่ | ติดชาร์ตครั้งแรกในช่วงข้อมูลภายในช่วงที่เลือก จึงไม่มีอันดับเดิม |
| กลับมา | เคยติดมาก่อน แต่ไม่ติดในวันที่เปรียบเทียบ (ไม่นับเป็นการไต่ขึ้น) |

> คำนวณจากประวัติอันดับจริงในข้อมูล ไม่ใช่การทำนายของโมเดล

## 5. หน้า โมเดล (Models)

เปรียบเทียบโมเดลจัดกลุ่ม 3 แบบที่ฝึกบนคุณลักษณะชาร์ตชุดเดียวกัน (ปรับสเกลด้วย StandardScaler, ทดลอง k = 2–8, เลือก k ด้วย Silhouette สูงสุดเหมือนกัน)

| โมเดล | แนวคิด | การจัดสมาชิก | รูปร่างกลุ่มที่ถนัด |
|---|---|---|---|
| **K-Means** | จัดเพลงเข้าจุดศูนย์กลางที่ใกล้ที่สุด แล้วย้ายจุดศูนย์กลางไปที่ค่าเฉลี่ย วนจนนิ่ง | Hard | ทรงกลม ขนาดใกล้กัน |
| **Hierarchical (Ward)** | เริ่มจากเพลงละกลุ่ม รวมคู่ที่เพิ่มความแปรปรวนน้อยสุดไปเรื่อยๆ แล้วตัดต้นไม้ให้เหลือ k กลุ่ม | Hard | ตามโครงสร้างต้นไม้ |
| **Gaussian Mixture** | มองข้อมูลเป็นการแจกแจงปกติหลายก้อน ใช้ E-step / M-step หาค่าที่เหมาะ | Soft (ความน่าจะเป็น) | วงรี ขนาดต่างกันได้ |

**ส่วนต่างๆ ในหน้า**
- **การ์ดโมเดล** — แผนภาพหลักการ, k ที่เลือก, Silhouette, ขั้นตอนการทำงาน 3 ขั้น, จุดเด่น/ข้อจำกัด และปุ่ม **ใช้โมเดลนี้**
- **ตารางเปรียบเทียบ** — คุณสมบัติของวิธี + ผลบนข้อมูล: Silhouette ↑, Davies–Bouldin ↓, Calinski–Harabasz ↑ (ป้าย "ดีสุด" ที่ค่าดีที่สุด), ขนาดกลุ่ม, ความมั่นใจเฉลี่ยและจำนวนเพลงก้ำกึ่ง (เฉพาะ GMM), เวลาฟิต · ชี้เมาส์ที่ชื่อตัวชี้วัดเพื่อดูคำอธิบาย
- **Silhouette ต่อ k** — เส้นของทั้ง 3 โมเดล จุดทึบ = k ที่แต่ละโมเดลเลือก
- **ความสอดคล้อง (ARI)** — ตาราง Adjusted Rand Index ระหว่างคู่โมเดล (1 = แบ่งเหมือนกันทุกเพลง, 0 = ไม่ต่างจากสุ่ม)
- **PCA แยกตามโมเดล** — แผนที่เดียวกัน 3 ภาพ สีตามกลุ่มของแต่ละโมเดล เห็นชัดว่าโมเดลแบ่งต่างกันตรงไหน

> ตัวชี้วัดทั้งสามวัดความ "แยกกันชัด" เชิงเรขาคณิต ไม่ได้บอกว่ากลุ่มไหนมีความหมายทางดนตรีมากกว่า

## 6. หน้า เพลงคล้าย (Finder)

ค้นหาเพลงแล้วดู **5 เพลงที่มีรูปแบบการติดชาร์ตใกล้เคียงที่สุด**

- **ช่องค้นหา** — พิมพ์ชื่อเพลงหรือศิลปิน (บางส่วนก็ได้ ไม่สนตัวพิมพ์) ชื่อที่ตรงทั้งหมดขึ้นก่อน ถ้ามีหลายเพลงชื่อซ้ำจะมีป้าย "ชื่อซ้ำ" พร้อม Track ID ให้เลือกถูกเพลง
- **กลุ่มเดียวกัน** — ติ๊กเพื่อแนะนำเฉพาะเพลงที่อยู่กลุ่มเดียวกับเพลงตั้งต้น (ตามโมเดลที่เลือก)
- **รายการแนะนำ** — เพลงตั้งต้นด้านบน (เส้นขาว) ตามด้วย 5 เพลง: ความคล้าย (%) แถบความคล้าย และกลุ่ม · คลิกเพลงเพื่อใช้เป็นเพลงตั้งต้นต่อ
- **ประวัติอันดับ** — เส้นอันดับของเพลงตั้งต้น (เส้นหนาสีขาว) และ 5 เพลงที่แนะนำ จัดแนวตามวันที่เข้าชาร์ต สีเส้นตรงกับขีดสีหน้าชื่อเพลงในรายการ · ชี้เมาส์ดูอันดับรายวัน
- **ประเมินเทียบการสุ่ม** — แถบพับได้ แสดงผลเฉลี่ย (แนะนำ vs สุ่ม) คลิกเพื่อดูตารางรายเพลง

**วิธีคำนวณ:** Cosine Similarity บนคุณลักษณะชาร์ต 4 ตัว (อันดับดีสุด, อันดับมัธยฐาน, จำนวนวันที่ติดชาร์ต, วันถึงอันดับสูงสุด) ที่ปรับสเกลแล้ว
— สูตรเดียวกับ `thai_chart_ml/recommend.py` · ผลการแนะนำ **ไม่ขึ้นกับโมเดลจัดกลุ่ม** ยกเว้นเมื่อติ๊ก "กลุ่มเดียวกัน"

## 7. หน้า ข้อมูล (Data)

### นำเข้าข้อมูล (อัปโหลดไฟล์)

ลากไฟล์มาวางในกรอบ หรือคลิกเพื่อเลือกไฟล์ (เลือกหลายไฟล์พร้อมกันได้)

| ไฟล์ที่วาง | สิ่งที่เกิดขึ้น |
|---|---|
| `charts.csv` | อัปโหลดไปที่ `data\raw\charts.csv` |
| `archive.zip` จาก Kaggle | อัปโหลดแล้วแตกเอา `charts.csv` ออกมาให้อัตโนมัติ |
| `spotify_songs.csv` | อัปโหลดไปที่ `data\raw\spotify_songs.csv` |
| `dashboard.json` | เปิดผลลัพธ์นั้นในเบราว์เซอร์ทันที (ไม่อัปโหลด ไม่ต้องใช้เซิร์ฟเวอร์) |

- หน้าเว็บ **ดูหัวตารางเพื่อแยกประเภทไฟล์ให้เอง** (ชาร์ตต้องมี `rank`, `region`, … / ข้อมูลเสียงต้องมี `track_id`, `danceability`, …)
- มีแถบความคืบหน้าระหว่างอัปโหลด และ **ถามก่อนแทนที่ไฟล์เดิม**
- ถ้าคอลัมน์ไม่ครบ ไฟล์จะถูกปฏิเสธพร้อมข้อความบอกสาเหตุ และ **ไฟล์เดิมไม่ถูกแตะต้อง**
- กล่องสถานะด้านขวาบอกว่ามี `charts.csv` / `spotify_songs.csv` แล้วหรือยัง (ขนาดไฟล์) และตอนนี้กำลังแสดงข้อมูลชุดไหน

### วิเคราะห์ใหม่

ปุ่ม **วิเคราะห์ใหม่** มุมขวาบนของการ์ด รันขั้นตอนเดียวกับ `python -m thai_chart_ml run` ในเบื้องหลัง
แสดงบันทึกการทำงานล่าสุดระหว่างรัน และเมื่อเสร็จหน้าเว็บจะโหลดผลใหม่ให้อัตโนมัติ
(ถ้ายังไม่มี `charts.csv` จะรันด้วยข้อมูลจำลอง)

> อัปโหลด `.csv` / `.zip` และปุ่มวิเคราะห์ใหม่ ใช้ได้เมื่อเปิดผ่าน `python -m thai_chart_ml serve` เท่านั้น
> ไฟล์ `charts.csv` มีขนาดประมาณ 3.4 GB การอัปโหลดผ่านเบราว์เซอร์ใช้เวลานาน — อัปโหลด `archive.zip` จะเร็วกว่า หรือคัดลอกไฟล์ไปวางใน `data\raw\` เองก็ได้

### คุณภาพข้อมูล

ช่วงวันที่มีในไฟล์และช่วงที่วิเคราะห์, จำนวนวันที่มีข้อมูล/วันที่ขาด, จำนวนแถวที่ตัดออก (ไม่มี track_id, อันดับไม่ถูกต้อง, ซ้ำ),
อันดับขัดแย้ง และผลการจับคู่ข้อมูลเสียง พร้อมข้อความจากการรันล่าสุด (กดขยายได้)

## 8. ตัวเลือกโมเดล

ปุ่ม **โมเดล ▾** มุมขวาบนของทุกหน้า เลือกได้ 3 โมเดล (แสดง k และ Silhouette ของแต่ละตัว)
เมื่อเปลี่ยนโมเดล สิ่งที่เปลี่ยนตาม:

- สีและรูปทรงกลุ่มบนแผนที่ PCA และการ์ดโปรไฟล์กลุ่ม
- กราฟ Silhouette ต่อ k และ KPI จำนวนกลุ่ม
- กราฟเฉลี่ยตามกลุ่มในหน้าไต่อันดับ
- ตัวเลือก "กลุ่มเดียวกัน" และ % กลุ่มเดียวกันในหน้าเพลงคล้าย
- ความน่าจะเป็นของการเป็นสมาชิก (เฉพาะ Gaussian Mixture)

หน้าเว็บจำโมเดลที่เลือกไว้ในเบราว์เซอร์ เปิดครั้งหน้าจะใช้โมเดลเดิม

## 9. ข้อมูลจริงกับข้อมูลจำลอง

- ถ้ามีผลจาก `charts.csv` จริง (`outputs\real\dashboard.json`) หน้าเว็บจะแสดงผลนั้น
- ถ้ายังไม่มี จะแสดงผลจาก **ข้อมูลจำลอง** ที่สร้างไว้ทดสอบโค้ด — ท้ายหน้าจะมีคำว่า "ข้อมูลจำลอง" กำกับ
  ตัวเลขชุดนี้ **ห้ามนำไปอ้างเป็นผลของชาร์ตไทย**
- ชื่อเพลงในข้อมูลจำลองเป็น "Synthetic Song …" ทั้งหมด

## 10. รองรับหน้าจอและการเข้าถึง

- **ธีมมืด/สว่าง** — ปุ่ม ☀/☾ ด้านล่างเมนูซ้าย (ค่าเริ่มต้นธีมมืด และจำค่าที่เลือก)
- **หน้าจอกว้าง ≥ 1280 px** — 3 คอลัมน์: เมนู | เนื้อหา | แถบขวา
- **แท็บเล็ต** — แถบขวาย้ายไปอยู่ใต้เนื้อหา
- **มือถือ ≤ 720 px** — เมนูกลายเป็นแถบล่างจอ การ์ดเรียงคอลัมน์เดียว
- ทุกกราฟชี้เมาส์ดูค่าได้ และแยกกลุ่มด้วย **สี + รูปทรง** (ไม่พึ่งสีอย่างเดียว)
- แอนิเมชันทั้งหมด (ปกเพลง แผ่นเสียง EQ) **หยุดเองเมื่อเครื่องตั้งค่า "ลดการเคลื่อนไหว"** และปกเคลื่อนไหวหยุดวาดเมื่อเลื่อนพ้นจอ

**ข้อมูลที่หน้าเว็บอ่าน** — `dist/data/real.json` และ `dist/data/synthetic.json` (คัดลอกจาก `outputs/<source>/dashboard.json`) มีฟิลด์หลัก:

| ฟิลด์ | เนื้อหา |
|---|---|

| `evaluation` | ผลประเมินเทียบการสุ่ม |
| `data_quality`, `audio_stats` | คุณภาพข้อมูลและการจับคู่ข้อมูลเสียง |

## 12. API ของเซิร์ฟเวอร์

`python -m thai_chart_ml serve` (โค้ดใน `thai_chart_ml/server.py`) เสิร์ฟหน้าเว็บและมี API สำหรับหน้า ข้อมูล:

| คำขอ | หน้าที่ |
|---|---|
| `GET /api/status` | สถานะไฟล์ใน `data\raw` และสถานะการรันล่าสุด (พร้อมบันทึก 40 บรรทัดท้าย) |
| `POST /api/upload?kind=charts` | อัปโหลด `charts.csv` หรือ `.zip` |
| `POST /api/upload?kind=songs` | อัปโหลด `spotify_songs.csv` หรือ `.zip` |
| `POST /api/run` | เริ่มวิเคราะห์ใหม่ในเบื้องหลัง |

**ความปลอดภัย**
- เซิร์ฟเวอร์ฟังเฉพาะ `127.0.0.1` (เข้าจากเครื่องอื่นไม่ได้)
- รับเฉพาะคำขอที่ Host เป็น `127.0.0.1` / `localhost` และคำขอ POST ต้องมีส่วนหัว `X-Thai-Chart: 1`
  เว็บไซต์อื่นที่เปิดอยู่ในเบราว์เซอร์จึงส่งไฟล์หรือสั่งรันแทนผู้ใช้ไม่ได้
- เขียนไฟล์ได้เฉพาะ 2 ชื่อที่กำหนดใน `data\raw\` เท่านั้น และเขียนลงไฟล์ชั่วคราวก่อน ตรวจผ่านแล้วจึงแทนที่ไฟล์เดิม

## 13. ข้อจำกัดที่ควรรู้

- **ภาพปก** ในการ์ดอันดับล่าสุดเป็นภาพประกอบตกแต่ง ไม่ใช่ปกจริงของเพลงนั้น (ข้อมูลไม่มีภาพปก) ส่วนปกในการ์ดมาแรงและแถบขวาเป็นภาพ generative ที่สร้างจาก Track ID
- **แอนิเมชันเป็นภาพเคลื่อนไหวเท่านั้น** ไม่มีการเล่นเสียงเพลง
- **การไต่อันดับ** ดูจากชาร์ต Top 200 เท่านั้น เพลงที่หลุดชาร์ตจะไม่มีอันดับ
- **การประเมินผล** เป็นการตรวจเชิงสำรวจจากข้อมูลชุดเดียวกับที่ใช้แนะนำ ไม่ใช่การพิสูจน์ความแม่นยำ
- `npm run dev` ไม่มี API อัปโหลด — ทดสอบหน้า ข้อมูล ด้วย `npm run build` แล้ว `python -m thai_chart_ml serve`
- การเปิด `dashboard.json` จากเครื่อง อยู่ในเบราว์เซอร์เท่านั้น รีเฟรชหน้าแล้วจะกลับไปใช้ผลจากเซิร์ฟเวอร์
